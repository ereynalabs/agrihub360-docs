---
title: "Reading the Pack"
description: "What is in a compliance pack sent from AgriHub360, in the order an inspection looks for it."
---

You have been sent a link by a farm that keeps its record in AgriHub360. The link downloads a zip. This page says what you will find in it and how to read it.

## The Cover

The first page names the farm, the year and the nation whose rules the pack follows. Under them is the **inspection-ready checklist** as it stood when the pack was built: the items an inspection asks for first, each marked met or not met, and, for a gap, what is missing in words. A gap is printed as a gap. The contents list names every document and file in the zip.

## The Documents

Each document is in the layout its regime already uses, so it reads like the record you know.

| Document | Layout | Holds |
|---|---|---|
| NVZ record | Defra's farm record and field record sheets | Each field's applications with the crop's N-max and the 250 kg field limit checked, the closed periods checked; the farm's livestock, imports and exports |
| Nutrient management plan | Tried & Tested farm and field sheets | The RB209 plan per field and what was applied against it |
| Manure management plan | Defra's order | The livestock loading against 170 kg N/ha, storage, where manure can go, the heap register, the risk map |
| Plant protection product record | The Voluntary Initiative's columns | Every application, the legal minimum marked, the assurance columns where the farm held them |
| Farm map and siting checks | The pack's own | The map, and every siting distance measured against the rule |
| SFI pack | The agreement's terms | Each action's evidence and its declaration window |
| EUDR dossier | Annex II | Each plot's packet and a draft due diligence statement |

Where the farm did not hold something a record asks for, the column is printed with "not recorded". The software does not leave a column out to hide a gap.

## Measured or Modelled

Every number in the record says which it is. A **modelled** value names the model behind it. A **measured** value names the device and the time it came from. Soil temperature from a probe in the field and soil temperature from a public weather model are both printed, and never mixed without saying so.

## The Share Link

The link downloads the pack as it was when the farm built it. It needs no account and stops working after the number of days the farm chose, at most 90. If it has stopped, ask the farm for a new one; nothing is lost, the pack is rebuilt from the same record.

## The Machine-Readable Files

Beside the PDFs the zip holds the same records as JSON and CSV, and a manifest naming each file. They are for a system that reads records, not for the visit.
