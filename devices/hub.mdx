The **AgriHub360 Hub** is the gateway for [AgriHub360 Sensors](/devices/sensor). A Hub covers the sensors within its radio range, so a small farm needs one and a large or hilly farm needs more. It receives LoRa uplinks from each sensor and posts them to the [Device API](/quickstart) over a wired or cellular connection.

## How It Posts

The Hub posts one request per reading, using the API key of the sensor that produced it. Each sensor stays a separate device in AgriHub360, so you can revoke or replace one without touching the others.

Three sensors reach one Hub over LoRa, and the Hub makes a separate request for each of them.

## Do You Need One?

Only for AgriHub360 Sensors. Your own hardware posts to the Device API directly. See [Bring Your Own Sensor](/devices/byod).
