## What It Tells You

The **field timeline** puts everything the field knows on one time axis: the soil readings, the modelled values, the forecast, the NDVI captures and the growth stage. A moisture drop lines up with the hot week that caused it. A greenness dip lines up with the frost before it. A measured reading sits next to the modelled value it replaced, so you can see how far the estimate was out.

## How It Works

Every reading posted to the Device API and every row a model writes lands on the field timeline. Each point is labelled **measured**, with the device and the time, or **modelled**, with the model named.
