A **decision window** is a yes-or-no answer to one question: is now the time? The windows cover drilling, spraying, applying nitrogen and treating for aphids.

Each window is a model that runs every day on the field's weather, readings and growth stage. The method behind each one is in [Models](/models/overview). Custom triggers add your own thresholds on any reading, on frost, wind or rain, or on a sensor that has gone quiet.

Each window reports open, approaching or closed. Every alert names the reading behind it.

## What's Included

Status is graded against the app as it is today. **Live** means built and working in the app. **In build** means being built and not on farms yet.

| Feature | What it does | Status |
|---|---|---|
| [Today's Decisions](/features/decision-windows/todays-decisions) | The week's decisions ranked, what the law wants first | Live |
| [Drilling Window](/features/decision-windows/drilling-window) | Soil temperature held N days, per crop and soil type | Live |
| [Spray Window](/features/decision-windows/spray-window) | Delta-T band plus frost cut-off, hour by hour | Live |
| [Nitrogen Timing](/features/decision-windows/nitrogen-timing) | Apply or hold, from temperature, moisture and rain | Live |
